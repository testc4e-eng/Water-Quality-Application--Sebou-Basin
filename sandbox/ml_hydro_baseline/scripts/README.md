# Scripts Sandbox

Scripts à ajouter uniquement pour exécution locale sandbox.

Règles:

- aucun script ne doit écrire en base ;
- toute extraction DB doit utiliser un rôle/session lecture seule ;
- tout output doit être écrit dans `sandbox/ml_hydro_baseline/runs/` ou `datasets/` ;
- aucun résultat ne doit être promu comme scientifique ou officiel.
