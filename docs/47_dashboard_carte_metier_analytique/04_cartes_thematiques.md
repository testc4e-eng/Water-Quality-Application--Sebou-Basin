# Cartes Thématiques

Représentation spatiale avancée des valeurs.

## Types de cartes prévus :
* Carte par valeur brute.
* Carte par disponibilité (absence/présence).
* Carte par tendance.
* Carte par anomalie.
* Carte réglementaire (classes de couleurs, V2).

Les légendes dynamiques s'adapteront aux palettes et classes configurées, notamment les seuils réglementaires (marocains) lorsqu'ils seront disponibles.
