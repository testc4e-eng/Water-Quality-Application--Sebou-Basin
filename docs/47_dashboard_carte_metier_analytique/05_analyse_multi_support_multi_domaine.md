# Analyse Multi-Support et Multi-Domaine

Objectif : Permettre à l'expert de croiser et de comparer plusieurs données différentes sur un même référentiel spatial.

## Fonctionnalités (Sprint 3)
* Constructeur d'analyse.
* Ajout de plusieurs "séries analytiques".
* Graphes multi-axes synchronisés.
* Tableaux synchronisés.
* Scénarios d'analyse croisée : Comparaison débit / lâcher / qualité de l'eau / données climatiques.
* Export CSV consolidé.
