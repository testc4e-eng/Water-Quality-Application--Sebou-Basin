# Supports, Domaines et Paramètres

La carte métier est conçue pour accueillir de multiples dimensions :

## Supports
* Stations qualité (Rivières, Barrages, Souterrain)
* Stations hydrométriques
* Stations pluviométriques / climatiques
* Pressions et pollutions : Rejets, STEP, Huileries, Décharges, Mines.

## Domaines
* Qualité
* Hydrologie (Débit, Lâcher)
* Météorologie (Précipitations, Températures)
* Pollution (Charge polluante, Rejets)

Chaque combinaison Support/Domaine donne accès à une liste dynamique de **paramètres**, gérée par le modèle unifié de séries analytiques.
