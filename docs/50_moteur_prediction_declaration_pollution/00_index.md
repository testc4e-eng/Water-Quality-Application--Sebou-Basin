# Moteur prediction declaration pollution

## Finalite

Ce dossier ouvre le cadrage documentaire du futur `moteur prediction declaration pollution`.

Il ne lance pas un chantier IA autonome hors priorite. Il cadre une brique cible qui devra se brancher sur le workflow `Declaration Pollution` une fois le MVP metier stabilise.

## Position dans la phase projet

```text
PHASE 3  Finalisation du MVP                       En cours
PHASE 4  Stabilisation plateforme                  A venir
PHASE 5  Validation metier finale / preprod        A venir
PHASE 6  Deploiement                               A venir
```

Dans cette phase, le moteur prediction doit etre traite comme :

1. un chantier de documentation et de conception ;
2. un consommateur futur des donnees du workflow `Declaration Pollution` ;
3. une brique strictement subordonnee aux validations metier, data et propagation.

## Regle de pilotage

Le dossier 50 ne doit pas contredire les priorites deja posees :

- `Dashboard Home` reste le premier blocage demonstrateur ;
- `Declaration Pollution` reste le coeur du MVP ;
- la prediction officielle ne doit pas devancer la qualification metier et scientifique ;
- aucun livrable ne doit presenter une prediction comme `operationnelle` a ce stade.
