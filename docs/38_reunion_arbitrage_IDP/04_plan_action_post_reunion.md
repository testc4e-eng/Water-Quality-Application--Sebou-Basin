# Plan d’action post-réunion — Arbitrage IDP 2024

## Phase 1 — Quarantaine

- isoler les paramètres non mappés
- isoler les paramètres ambigus
- isoler les valeurs non numériques et les valeurs labo spéciales
- isoler les sources non rattachées
- isoler les recouvrements entre `globale` et `marché cadre`

## Phase 2 — Mapping

- valider le dictionnaire officiel des paramètres
- valider les unités officielles
- publier la liste officielle des codes pollution
- rattacher les points source validés
- qualifier les points `amont` / `aval`

## Phase 3 — Nettoyage

- appliquer uniquement les règles validées en réunion
- supprimer seulement les cas explicitement autorisés
- conserver les cas non tranchés en attente
- tracer chaque décision dans le tableau de validation

## Phase 4 — Intégration

- intégrer uniquement les données validées
- conserver la traçabilité de l’origine
- vérifier l’impact sur les synthèses et tableaux de bord
- planifier un point de contrôle final avec le métier
