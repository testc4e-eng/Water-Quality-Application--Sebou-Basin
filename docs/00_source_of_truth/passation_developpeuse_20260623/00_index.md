# Dossier de passation développeuse — SAD/WQDSS

## Objet

Ce dossier regroupe les éléments minimum à transmettre à la développeuse pendant l'absence du chef de projet :

- vision d'ensemble du projet ;
- rapport détaillé et synthèse de passation ;
- validation post-réorganisation ;
- audit Git du code de continuité ;
- liste des exclusions Git ;
- résumé du commit local de continuité ;
- patch du commit local non poussé.

## Lecture recommandée

1. lire `01_note_cadrage_deploiement_et_reprise.md`
2. lire `04_synthese_passation_conge_chef_projet_20260623.md`
3. lire `02_etat_global_projet_20260622.md`

5. utiliser `09_patch_commit_local_2221edf.patch` seulement si le code de continuité doit être rejoué sur un autre clone
