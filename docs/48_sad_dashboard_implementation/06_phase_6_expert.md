# Phase 6 - Expert

## Objectif

Créer un espace unique pour les lectures détaillées sans polluer les parcours DG/métier.

## Principe

Réutiliser les écrans experts existants.

Ne pas recréer de nouveaux moteurs.

## Périmètre

- qualité expert
- hydraulique expert
- propagation expert

## Contenu autorisé

- paramètres
- seuils
- diagnostics
- confiance hydraulique
- propagation détaillée
- diagnostics snap

## Sources de réutilisation

- écrans qualité réglementaire enrichis
- composants décisionnels test réorientés expert
- restitution des endpoints propagation MVP
- vues d'analyse spécialisées

## Règle UX

Le niveau expert doit être accessible, mais jamais imposé à la DG.

## Risque principal

Mélanger ce niveau avec les écrans métier et rendre l'ensemble illisible.
