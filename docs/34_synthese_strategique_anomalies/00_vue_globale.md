# Vue globale des anomalies

## Objectif

Donner une lecture rapide et directement exploitable par la direction, le chef de projet et les parties prenantes métier.

Cette synthèse ne reprend pas chaque anomalie en détail. Elle regroupe les sujets par problèmes racines afin de préparer les arbitrages.
Cette synthese ne qualifie pas le projet comme bloque. Elle structure les ecarts documentes afin de preparer les arbitrages metier.

## Nombre total d'anomalies

- 15 fiches analysées

## Nombre de blocs stratégiques

- 4 blocs stratégiques

## Tableau de synthèse

| Bloc | Problème racine | Nombre anomalies | Priorité | Décision requise |
|---|---|---:|---|---|
| Paramètres | Paramètres non stabilisés | 4 | Critique | Oui |
| Pollution | Absence de structuration claire de la pollution | 3 | Critique | Oui |
| Données | Données incomplètes ou non exploitables | 4 | Critique | Oui |
| Référentiels | Référentiels non alignés | 3 | Élevée | Oui |

## Lecture stratégique

Les anomalies ne relèvent pas toutes du même niveau de gravité. Le projet fait surtout face à quatre problèmes racines :

- les paramètres ne sont pas encore totalement stabilisés ;
- le domaine pollution n'est pas encore structuré de façon suffisamment claire ;
- certaines données sont incomplètes, absentes ou difficilement exploitables ;
- les référentiels ne sont pas encore totalement alignés entre eux.

Le point principal pour la réunion n'est donc pas de revoir 15 cas séparés, mais de décider :

- quel dictionnaire métier fait foi ;
- quel périmètre pollution est retenu ;
- quelles données peuvent être utilisées immédiatement ;
- quel référentiel devient la référence officielle.

## Lecture de responsabilite

- mission projet : identifier, tracer, qualifier et documenter les ecarts ;
- responsabilite metier/client : arbitrer les cas ambigus et confirmer les references officielles.
