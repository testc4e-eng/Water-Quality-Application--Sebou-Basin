# SAD Dashboard Decision First

## Objet

Ce dossier formalise la nouvelle génération de dashboards SAD selon une approche :

- `DECISION_FIRST`
- `METIER_FIRST`
- `DG_FIRST`
- `USER_EXPERIENCE_FIRST`

Le SAD est traité ici comme un système d’aide à la décision pour le pilotage du bassin du Sebou, et non comme une simple plateforme SIG ou une plateforme de visualisation de données.

## Règle de lecture

1. Lire d’abord l’état réel.
2. Vérifier ce qui est conservé, fusionné et créé.
3. Lire le catalogue KPI avant toute implémentation DG/métier.
4. Considérer l’hydraulique validée et le backend propagation MVP V1 comme acquis, non à réouvrir.
