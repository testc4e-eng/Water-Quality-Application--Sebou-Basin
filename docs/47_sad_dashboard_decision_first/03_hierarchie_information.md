# Hiérarchie information

## Niveau 1 — Métier / DG

Afficher :

- KPI globaux
- alertes
- tendances
- carte synthèse
- priorités
- recommandations
- niveau de confiance

Masquer :

- IDs
- lineage
- batchs
- codes techniques
- statuts QA détaillés
- détails API
- référentiels

## Niveau 2 — Expert

Afficher :

- paramètres
- seuils
- non classifiables
- fraîcheur
- couverture
- confiance hydraulique
- diagnostics propagation
- diagnostics de snapping
- distinction explicite air / eau pour température

## Niveau 3 — Administration

Afficher :

- ingestion
- monitoring
- logs
- QA
- référentiels
- statuts de vues
- statuts d’APIs

## Règles UX

- la même donnée ne doit pas apparaître avec le même niveau de détail partout
- le détail doit apparaître au clic, pas au premier écran
- le langage DG doit être court et actionnable
- les formulations techniques doivent être réservées aux niveaux expert et admin
