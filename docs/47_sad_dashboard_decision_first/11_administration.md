# Administration

## Rôle

Conserver les écrans techniques, mais les sortir du parcours métier de premier niveau.

## À conserver

- ingestion
- batchs
- monitoring
- QA
- référentiels
- utilisateurs et audit
- couverture data

## Principe

L’administration ne doit plus polluer la lecture DG/métier.

## Écrans à conserver

- `/admin/data-scan`
- `/admin/gestion-users`
- `/admin/ingestion`
- `/admin/popup-rules`
- `/data`

## Recommandation navigation

- regrouper ces routes sous un espace admin explicite
- retirer les termes techniques du niveau DG
