# Catalogue global paramètres

## Règles absolues

- `MO` = matières organiques ; `Mo` = molybdène.
- `FM` et `F_M_MES` sont exclus de la restitution publique.
- `MD` reste en attente de validation client.
- Les statuts `CONSULTATION_ONLY`, `HORS_RESTITUTION`, `LEGACY`, `PIPELINE_FUTUR` et `DOUBLE_CLASSIFICATION` doivent être conservés jusqu'à arbitrage métier contraire.

## Notes de lecture

- Les volumes exacts documentés au niveau vue priment sur les volumes approximatifs de famille.
- `Date min` / `Date max` restent souvent `NON_DOCUMENTE_AUDIT` faute de borne temporelle consolidée dans les sources lues ; cela doit être complété par un audit SQL read-only dédié si nécessaire.
- Les endpoints `/api/v1/qualite/*` sont réellement disponibles seulement pour `metaux`, `chimie-minerale`, `physicochimie`, `pollution-organique`.
- Les autres endpoints de cette matrice sont des cibles documentées et non des contrats observés en production à date.
