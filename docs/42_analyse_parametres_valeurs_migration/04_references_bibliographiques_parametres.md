## Paramètre : As

- Nom standard : As
- Unité : mg/L
- Sources consultées :
  - WHO — Arsenic fact sheet — https://www.who.int/news-room/fact-sheets/detail/arsenic
- Plages / seuils trouvés : <= 0.01 mg/L
- Type d’eau concerné : drinking-water
- Comparaison avec ABH : référence ABH non disponible
- Conclusion : Valeur guide OMS provisoire 10 µg/L.
- Niveau de confiance : élevé
