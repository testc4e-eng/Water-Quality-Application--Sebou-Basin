# Points à valider métier

| Sujet | Question | Options | Recommandation | Priorité |
|---|---|---|---|---|
| Choix des grilles | Utiliser ancienne grille générale ou nouvelles grilles simplifiées ? | ancienne / nouvelle / les deux | Conserver les deux avec statut distinct jusqu’à arbitrage | Critique |
| Rivières vs lacs vs souterraines | Les types d’eau doivent-ils avoir des seuils séparés ? | oui / non | Oui | Critique |
| Unités officielles | Quelle unité officielle retenir par paramètre ? | PDF / référentiel / corrigée | Valider paramètre par paramètre | Critique |
| Intervalles ouverts | Comment interpréter `<`, `<=`, `>`, `>=` et `+ de` ? | strict / inclusif | Conserver l’opérateur PDF | Élevée |
| Paramètre le plus pénalisant | Appliquer cette règle au SAD ? | oui / non / contexte | Oui après validation métier | Critique |
| Paramètres absents | Comment traiter un paramètre absent du référentiel ? | non classable / création mapping | Non classable avant mapping | Élevée |
| Familles | Les familles proposées sont-elles correctes ? | accepter / corriger | Revue métier rapide | Moyenne |
| Codes existants | Les correspondances proposées sont-elles valides ? | match / conflit / absent | Ne pas modifier le canonique sans arbitrage | Critique |
| Statut réglementaire | Le nouveau système est-il officiel ou projet ? | officiel / projet / interne | À confirmer ; le PDF indique “projet” | Critique |
| Couleurs | Palette ancienne ou nouvelle pour l’interface ? | ancienne / nouvelle | Suivre la grille utilisée | Moyenne |
