# Sources de Données - WQDSS

## 1. Données de Qualité d'Eau
- **Paramètres mesurés** : Oxygène dissous, azote, phosphore, métaux lourds.
- **Fréquence** : Mensuelle ou temps réel dépendamment des points.

## 2. Données SIG (Spatial)
- Réseau hydrographique (Sebou).
- Occupation du sol (Corine Land Cover / Local ads).
- Modèle Numérique de Terrain (MNT).

## 3. Données Météorologiques
- Pluviométrie, température, évaporation (Stations ABHS).

---
*Toutes les données brutes doivent être déposées dans `data/raw/`.*
