# Mises a jour documentaires recommandees

## 1. Changement de posture documentaire

Il faut maintenant documenter le projet comme un `MVP en finalisation`, pas comme une plateforme deja entree en stabilisation complete.

## 2. Regles recommandees

1. un blocage critique = une fiche d'intervention rapide ;
2. le chantier `Declaration Pollution` = un programme documentaire dedie ;
3. la matrice metier = source principale de conception ;
4. les backlogs secondaires = maintenus, mais geles hors bugs bloquants ;
5. la stabilisation globale = phase ulterieure.

## 3. Priorites documentaires immediates

- contrat et diagnostic du `Dashboard Home` ;
- lecture structuree de la matrice metier ;
- specification workflow `Declaration Pollution` ;
- conception technique `BD + API + Front` ;
- cadrage integration propagation.

## 4. Ce qu'il faut repousser

Sauf bug bloquant :
- optimisation performance ;
- refonte UX globale ;
- harmonisation API complete ;
- nettoyage documentaire complementaire ;
- stabilisation approfondie des dashboards secondaires.
