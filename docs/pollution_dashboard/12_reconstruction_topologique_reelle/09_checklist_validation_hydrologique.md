# Checklist Validation Hydrologique

- [ ] Les confluences majeures sont-elles toutes nodées ?
- [ ] Le sens d'écoulement est-il préservé après le découpage (Z_Max amont, Z_Min aval) ?
- [ ] Les barrages et stations sont-ils toujours correctement snappés sur le nouveau réseau ?
- [ ] Le composant principal couvre-t-il les zones urbaines critiques (Fès, Meknès, Kenitra) ?
- [ ] Absence de micro-segments (< 1m) inutiles générés par ST_Node.
