# Registre de pilotage MVP

## Objectif

Ce dossier sert au pilotage operationnel du chemin critique.

Il centralise :
- les bugs bloquants MVP ;
- les dependances critiques ;
- les backlogs actifs ;
- les sujets volontairement geles.

## Regle

Tout sujet non bloquant pour le MVP doit rester en attente jusqu'a la phase de stabilisation plateforme.
