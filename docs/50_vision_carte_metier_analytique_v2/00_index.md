# Vision V2 — Dashboard Carte Métier Analytique

Ce dossier formalise la vision V2 du Dashboard Carte Métier Analytique. L'objectif est de passer d'un simple portail de données à un véritable environnement analytique de bassin.

## Architecture validée : les 3 modes d'analyse

| Mode | Logique utilisateur | Question métier | Niveau technique |
|------|---------------------|-----------------|----------------|
| **1. Affichage par Support** | "Je veux analyser *cette station*" | Objet métier + données disponibles | Sprint 2C (widgets) |
| **2. Affichage par Domaine** | "Je veux étudier *le Cadmium*" | Phénomène + supports concernés | Sprint 2D |
| **3. Cartes Thématiques** | "Je veux voir *l'état du territoire*" | Territoire + interpolation | Sprint 2E |
