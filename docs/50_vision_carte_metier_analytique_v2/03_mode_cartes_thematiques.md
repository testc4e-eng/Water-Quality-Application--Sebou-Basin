# Mode 3 — Cartes Thématiques (Sprint 2E)

**Objectif :** Analyse territoriale par interpolation et cartes prédéfinies.

Ce mode permet de voir "l'état du territoire" dans son ensemble, en s'appuyant sur les données de tous les supports pertinents pour une thématique donnée.

## 1. Climatologie
- Précipitations cumulées (1/3/6/12 mois) — interpolation IDW/Kriging
- Température moyenne (mensuelle, annuelle, anomalie)
- Évaporation (mensuelle, saisonnière)

## 2. Hydrologie
- Débits actuels (pastilles graduées)
- Débit spécifique (m³/s/km²)
- État des barrages (volume, %, variation)
- Lâchers / Apports

## 3. Qualité (V2 future — classification réglementaire)
- Indice global qualité (Excellent → Mauvais)
- Paramètre déclassant (DBO5, NH4, NO3, MES)
- Métaux lourds (Cd, Pb, Hg, As)
- Microbiologie (Coliformes, E.Coli)
- Oxygénation (O₂ dissous, DBO5, DCO)

## 4. Pollution
- Intensité pollution (nb sources/km²)
- STEP (charge polluante, conformité)
- Pression pollution (Faible → Critique)
