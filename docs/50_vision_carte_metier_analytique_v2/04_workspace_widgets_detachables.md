# Workspace Analytique V2 — Widgets détachables (Sprint 2C)

## 1. Chaque analyse devient un widget flottant

```text
┌─────────────────────┐
│ Débit Ouergha       │
│ [×] [_] [□]         │
│                     │
│  [GRAPHique]        │
│                     │
└─────────────────────┘
```

## 2. Fonctionnalités des widgets

L'environnement de travail doit être hautement flexible et personnalisable. Chaque widget offre les capacités suivantes :
- **Déplaçable** (Drag & Drop)
- **Redimensionnable**
- **Plein écran**
- **Réductible** (Minimize)
- **Export** (PNG pour les graphiques, CSV pour les données brutes)
- **Synchronisation temporelle** (Réaction aux filtres de période globaux)
