# Plan d’actions post-validation

## Actions immédiates

- enregistrer les décisions D1 à D4 ;
- figer la matrice de validation client ;
- qualifier le périmètre de préproduction retenu ;
- tracer les sujets validés, à confirmer ou à corriger.

## Actions à 30 jours

- appliquer les validations documentaires sur les référentiels et règles métier ;
- consolider le périmètre IDP validé ;
- mettre à jour la matrice GO / NO-GO ;
- préparer la préproduction conditionnée.

## Actions à 60 jours

- stabiliser les restitutions métier sur le périmètre validé ;
- exécuter la qualification fonctionnelle du périmètre préproduction ;
- documenter les cas maintenus hors périmètre officiel.

## Actions à 90 jours

- décider la clôture complète de la qualification ;
- confirmer le statut final de la préproduction ;
- basculer vers la feuille de route post-validation et d’enrichissement analytique.
