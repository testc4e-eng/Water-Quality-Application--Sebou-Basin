# Qualification métier préproduction - SAD Sebou

## Objet

Ce dossier regroupe les documents finaux destinés à fermer les derniers arbitrages métier ouverts avant le passage du SAD Sebou en préproduction.

Il ne s'agit pas d'un dossier de correction ou de blocage.

Il s'agit :

- d'une phase de qualification métier ;
- d'une phase d'arbitrage ;
- d'une phase de validation ;
- d'une étape normale de gouvernance des données.

## Principe directeur

Le projet a :

- migré les données ;
- exécuté les contrôles qualité ;
- identifié les incohérences ;
- documenté les écarts ;
- préparé les règles de traitement.

Les décisions restantes relèvent :

- du métier ;
- du propriétaire de la donnée ;
- du client.
